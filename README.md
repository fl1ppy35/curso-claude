# Claude 101 em português

Curso pessoal para aprender a usar o Claude, em português, seguindo a estrutura do
[Claude 101](https://academy.claude.com/courses/claude-101) da Anthropic Academy
(13 aulas em 4 módulos, mais quiz final). O texto é original, não é tradução.

Cada aula tem explicação curta, uma prática para fazer no próprio Claude e um quiz
com correção na hora. O progresso de cada aluno (Felipe, Arthur, Dayane) fica salvo
no navegador, com exportação para levar a outro aparelho.

## Como abrir

- Localmente: abra `index.html` no navegador.
- Publicado: ative o GitHub Pages neste repositório (branch `main`, pasta raiz).

## Arquivos

- `index.html`: a página (layout, navegação, quiz, progresso).
- `curso.js`: o conteúdo das aulas, práticas e quizzes.
